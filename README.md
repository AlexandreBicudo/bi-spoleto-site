# Site do BI Spoleto

Quadro público das sprints do Projeto Integrador de BI, somente leitura.

- Repositório do projeto (privado): https://github.com/AlexandreBicudo/bi-spoleto

## Como atualizar

1. Edite o controle e salve.
2. Rode `python docs/scripts/build_site.py` no projeto.
3. Envie `site/dados/estado.json` (e `site/index.html`, se a interface mudou) para este repositório.

Valores em reais são removidos na geração, porque este repositório é público.
